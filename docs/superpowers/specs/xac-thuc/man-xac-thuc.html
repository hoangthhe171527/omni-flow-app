      1

      Thêm “Tiếp tục với Apple”?

      App có Google mà chưa có Apple: App Store có thể từ chối (mục 4.8). Cần thêm API mới.

      2

      Bỏ ô tích Điều khoản ở Đăng ký?

      Thay bằng dòng “Khi tạo tài khoản, bạn đồng ý…” dưới nút, như Notion, Todoist.

      3

      Đặt mật khẩu mới ngay trong app?

      API đã có. App cần mở liên kết email (Universal Link); hiện đang mở trang web.
