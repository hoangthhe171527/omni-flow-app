Cần anh chốtBa điểm thiết kế phụ thuộc quyết định
1Nhãn chung công ty hay riêng từng kế hoạch? Hiện cả hệ thống dùng một bộ nhãn chung. Bản thiết kế giữ như vậy; nếu muốn mỗi kế hoạch có bộ nhãn riêng như app tham khảo thì phải đổi API và chuyển dữ liệu cũ.
2Thảo luận theo kế hoạch (WorkChat)? Viomni chưa có chat nội bộ nào. Bản thiết kế đã bỏ biểu tượng chat; nếu cần thì đó là một dự án riêng.
3Nền kế hoạch bằng ảnh tải lên? API cố ý chỉ nhận mẫu nền có sẵn. Bản thiết kế dùng nền màu; ảnh tải lên cần đổi API và lưu trữ ảnh.
